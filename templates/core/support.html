Sustainability

Radio Outdoors is being built with the understanding that no one is here forever. Software, documentation, finances, backups, credentials, and stewardship must be organized so the project can continue after its original founder or developers can no longer maintain it.

The project succeeds only if the stories remain available for the next generation.
