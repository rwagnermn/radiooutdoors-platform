Support Radio Outdoors

Radio Outdoors is free to use. Contributions help cover the real costs of keeping the service available, including hosting, maps, storage, backups, domain services, security, and continued development.

Contributing is always optional and does not unlock core features.

Email Radio Outdoors Support

Make a One-Time Contribution

Future payment options may include PayPal, credit card, and debit card.

Secure payment processing will be handled by established payment providers. Radio Outdoors will not store credit card numbers, CVV codes, or other sensitive card information.

Become a Sustaining Supporter

Sustaining Supporters will be able to provide recurring monthly support toward the ongoing operation of Radio Outdoors.

Becoming a Sustaining Supporter is optional. Core Radio Outdoors functionality remains available without payment.

Help Cover Infrastructure

Contributions may help cover:

  • Web hosting
  • Database hosting
  • Image and photo storage
  • Backups
  • Google Maps and API usage
  • Domain registration
  • Email services
  • Security services
  • Future scaling costs
Other Ways to Help

Financial support is not the only way to contribute:

  • Report bugs
  • Suggest improvements
  • Help test new features
  • Share Radio Outdoors with other amateur radio operators
  • Contribute technical skills
  • Help preserve club and amateur radio history
