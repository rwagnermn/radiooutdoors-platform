Choosing or creating a Location

Search for an existing Location first. If none fits where you operated, choose Create a New Location.

Give it a natural name such as Near Pike Lake, Forest Road Campsite, or North Shore Pull-off.

A street address is optional. Place the pin directly on the map to identify the Location. If an address places the pin incorrectly, remove or move the pin and select the correct position yourself.

Your Location pin may be publicly visible. Use an approximate nearby position if you do not want to disclose an exact cabin, home, or private operating site.
